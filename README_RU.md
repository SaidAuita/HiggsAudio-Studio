## Возможности

* **🎭 Флагманский движок: Fish Audio Drama 3 (35B MoE)** — студийное качество звука **Hi-Fi 44.1 кГц**, непревзойдённая естественность просодии, дыхание, человеческий ритм речи и актёрская выразительность. На сегодняшний день это золотой стандарт и самый качественный локальный движок для профессионального дубляжа и клонирования голоса.
* **🎬 Пакетный клон и перевод обучающих видеороликов** — автоматическая последовательная озвучка разбитых на части сценариев и субтитров (`ru-en.txt` ➔ `01.wav`, `02.wav`...), навигация по десяткам (`01-10`, `11-20`...), контроль качества каждого фрагмента с 1-клик переозвучкой и склейка готовых пакетов с настраиваемыми паузами (`01-33.wav`).
* **🎙️ Higgs Audio v3.1** — 43 инлайн-тега эмоций (`<|emotion:happy|>`), звуков (`<|sfx:laughter|>`), просодии и стилей + автоматическое обогащение текста локальной LLM или внешним API (LM Studio, Ollama, OpenAI).
* **🔥 FireRedTTS3 (DiT Flow Matching)** — кристальная чистота звука, мгновенное **создание голоса по описанию (Voice Design)** («*Спокойный, глубокий мужской голос 35 лет с тёплым бархатным тембром*») и **редактирование речи (Speech Edit)** (замена/удаление слов, изменение высоты тона и темпа).
* **🧬 Клонирование голоса (Zero-Shot)** — клонирование любого голоса по короткому аудио-образцу (3–6 сек) с автоматическим распознаванием текста (Moonshine ASR). Поддержка кросс-языкового клонирования (русский образец ➔ английская речь).
* **🧬 Длинный клон (Long Voice Cloning)** — озвучка больших текстов и книг с автоматической разбивкой на предложения, пошаговой генерацией, бесшовной склейкой, настраиваемыми паузами и авто-нумерацией файлов (`01.mp3`, `02.mp3`...).
* **🎬 Подкасты и Аудиокниги** — создание многоголосых диалогов и радиоспектаклей с автоматическим выравниванием громкости по стандарту EBU R128 (LUFS −16).
* **📦 Пакетная обработка (Batch)** — параллельная озвучка списков реплик с отображением прогресса в реальном времени.
* **🔇 Интеллектуальный VAD-фильтр хвостов** — алгоритм `trim_trailing_artifacts` исключает щелчки вокодера, шум и диффузионные галлюцинации на коротких фразах и одиночных словах.
* **🌐 100% Двуязычный интерфейс (RU 🇷🇺 / EN 🇬🇧)** — динамическое переключение языка в реальном времени без перезагрузки.
* **💾 Полное автосохранение GUI** — запоминание активного движка, под-вкладок, пресетов, квантизации (`bf16`, `8-bit`, `4-bit`, `fp32`) и параметров генерации между запусками.

### Платформы

| ОС | GPU | Статус | Ускорение |
|---|---|---|---|
| Windows 10/11 | NVIDIA RTX 30xx–50xx | ✅ протестировано | CUDA 12.8 / 12.6 + Triton / SDPA |
| Windows 10/11 | NVIDIA RTX 20xx / GTX 16xx | ✅ поддерживается | CUDA 12.6 / 11.8 |
| Windows / Linux | CPU only | ✅ поддерживается | Потоковый синтез на процессоре |

### Память и квантизация

| Видеопамять (VRAM) | Рекомендуемая конфигурация | Рекомендуемые движки |
|:---|:---|:---|
| **24 ГБ+** (RTX 3090/4090/5090) | Полная точность `bf16` + Режиссёр LLM (9–12B в 4-bit) | 🎭 Fish Audio Drama 3, Higgs Audio v3.1, FireRedTTS3 |
| **12–16 ГБ** (RTX 4070/4080/3060 12G) | `bf16` / `8-bit` + Режиссёр LLM (4–9B в 4-bit) | 🎭 Fish Audio Drama 3, Higgs Audio v3.1 (`8-bit`), FireRedTTS3 |

## Быстрый старт

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/SaidAuita/HiggsAudio-Studio.git
   cd HiggsAudio-Studio
   ```

2. **Установите окружение:**
   * Запустите `install.bat` и выберите версию CUDA вашей видеокарты (CUDA 12.8, 12.6, 11.8 или CPU).
   * Установщик автоматически настроит портативный Python 3.12, PyTorch и все зависимости.

3. **Загрузите веса Fish Audio Drama 3 (флагман):**
   * Запустите скрипт PowerShell:
     ```powershell
     powershell -ExecutionPolicy Bypass -File download_drama3.ps1
     ```
   * Либо веса моделей загрузятся автоматически при первом обращении в папку `models/`.

4. **Запуск:**
   * Запустите `run.bat`.
   * Интерфейс автоматически откроется в браузере по адресу `http://127.0.0.1:7860`.

## Пакетный клон и рабочий процесс перевода видео

Специально оптимизирован для перевода и дубляжа обучающих курсов, видеоуроков YouTube и коммерческих туториалов:

* **Автоматическая последовательная озвучка**: чтение структурированных файлов сценариев (`ru-en.txt`) и пошаговая генерация фрагментов (`01.wav`, `02.wav`...) прямо в папку `output/NUM/` с сохранением метаданных и сида.
* **Интерактивная навигация по десяткам**: удобное переключение диапазонов (`01-10`, `11-20`, `21-30`...) и 10 прямых кнопок быстрого доступа со статусом готовности (`✅ 21` готов, `⚪ 25` ещё нет) и предпросмотром текста реплик.
* **Контроль и переозвучка в 1 клик**: клик по любому фрагменту мгновенно загружает аудио в плеер для проверки, подставляет текст, задаёт точный диапазон (`21` по `21`) и снимает пропуск существующих для моментальной перегенерации, если не понравилась интонация.
* **Встроенная склейка фрагментов**: объединение проверенных файлов диапазона (например, от `01` по `33`) в единый файл `01-33.wav` (с защитой от перезаписи суффиксами `_01`, `_02`) и настраиваемой паузой между репликами (по умолчанию 0.5 сек).
* **Готовый формат и тестовый файл**: Тестовый сценарий на 5 фрагментов доступен в файле [`examples/batch_script_sample.txt`](examples/batch_script_sample.txt) с разметкой меток (`[01.wav]`) и языковых тегов (`RU:` / `EN:`).

## Нововведения и обновления форка

* **🎭 Интеграция флагманского движка Fish Audio Drama 3 (35B MoE, Hi-Fi 44.1 кГц)**:
  * Полноценная интеграция модели Drama 3 со студийной частотой дискретизации 44.1 кГц.
  * Архитектура с изолированным фоновым процессом-воркером (`drama_worker.py` + `drama_engine.py`), исключающая фрагментацию памяти CUDA и системные дедлоки буферов ввода-вывода.
  * Интеллектуальное кэширование эмбеддингов референсного голоса (`get_cached_reference`), устраняющее повторную работу Qwen3-ASR и кодека на каждом фрагменте пакета.
  * Автоматический скрипт загрузки модели `download_drama3.ps1`.
* **🎬 Пакетный клон и рабочий процесс перевода видео**:
  * Пошаговая пакетная генерация, навигация по десяткам, моментальная перегенерация выбранного фрагмента и склейка диапазона.
* **🔥 Интеграция FireRedTTS3**:
  * Полная поддержка моделей `FireRedTTS3-bf16`, `FireRedTTS3-fp32` и `FireRedTTS3-int8`.
  * Добавлены панели **Voice Design** (генерация уникальных голосов по тексту) и **Speech Edit** (семантическое и акустическое редактирование речи).
  * Кросс-языковое клонирование на базе CAM++ спикер-эмбеддингов.
* **🔇 Устранение концевых артефактов (VAD Tail Clean)**:
  * Модуль `trim_trailing_artifacts` устраняет шум вокодера, щелчки и диффузионные галлюцинации на коротких фразах.
  * Динамический расчёт диффузионных шагов, ускоряющий синтез коротких фраз до 3.5 раз.
* **⚡ Изоляция процессов LLM и совместимость с RTX 30xx/40xx/50xx**:
  * Фоновый демон `director_daemon.py` разделяет контексты CUDA между `llama.cpp` и `PyTorch`.
* **🧬 Длинное клонирование с автонумерацией**:
  * Пакетная генерация глав аудиокниг с авто-инкрементом номеров файлов (`01`, `02`, `03`...) в `output/NUM/`.
* **🌐 Полная локализация (RU / EN)**:
  * 100% покрытие перевода для всех элементов управления, вкладок, выпадающих списков, примеров и всплывающих подсказок.
